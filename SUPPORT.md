# Support / 支持范围

Use GitHub Discussions for setup, dataset-contract, algorithm and integration questions. Reproducible defects
belong in Issues. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).

安装、数据契约、算法和集成问题可使用 GitHub Discussions；可复现缺陷请提交 Issue；安全漏洞必须
遵循 [SECURITY.md](SECURITY.md) 私密报告。

This project does not provide a managed port-control service, site-integration SLA, safety certification or
emergency operational support. Production adoption requires separate agreements, authorized data, site
validation, accountable ownership and safety change management.

本项目不提供托管式港口控制服务、现场集成 SLA、安全认证或应急运行支持。生产采用需要另行完成
协议、数据授权、现场验证、责任划分与安全变更管理。
