# 第 27 步：Web 页面模块切换

## 完成内容

- 新增 Web 页面模块切换状态，当前支持五个模块：态势总览、沙盘推演、韧性评估、调度优化、应急预案。
- 底部控制台改为“两层结构”：上层显示当前模块内容，下层固定五个模块按钮。
- 态势总览模块展示事件流和五项核心 KPI。
- 沙盘推演模块展示开始、暂停、重置、时间推进、事件注入、倍速和推演时钟。
- 韧性评估模块展示网络韧性指数、恢复能力、关键节点压力、风险扩散和高压节点排行。
- 调度优化模块展示规则 AI 决策建议和当前推荐绿色调度策略。
- 应急预案模块展示事故封航、极端天气、港口瘫痪和能源管控四类预案。
- 五个模块按钮使用 `aria-pressed` 标识当前激活模块，并复用 HUD 模块按钮视觉规范。
- 浏览器验证五个按钮均可点击切换，且底部模块按钮无重叠。
