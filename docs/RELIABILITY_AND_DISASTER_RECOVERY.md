# 24×7 可靠性、持久化与灾难恢复

新增 `durable-state-envelope.v1` 状态存储层，用于需要将内存控制状态升级为可恢复状态的后续站点适配器。它提供：

- 载荷 SHA-256、前代状态摘要、整体信封 SHA-256 与严格递增代数。
- 同文件系统中写入临时文件、`fsync`、原子重命名和目录 `fsync`，权限为 0600。
- 保留上一代独立检查和自动回退读取，主状态损坏时不会静默接受。
- 追加式哈希日志，每次提交记录状态摘要、前日志哈希和序列。
- 乐观并发代数检查，防止旧读写入覆盖新状态。

`fencing-token.v1` 为主备提供有过期时间的租约和单调 fencing number。旧主节点即使网络恢复，也不能用过期 token 继续写入。文件租约只适用于单主机/共享一致文件系统；多故障域部署必须替换为具有 quorum 和线性一致性的租约存储。

可靠性验收目标为 RPO 15 分钟、RTO 60 分钟、月可用性 99.9%。`reliability-readiness.v1` 还会检查双副本、备份新鲜度、90 天内恢复演练、日志完整性、告警路由测试、运维手册复核和连续 30 天实测可用性。

当前自动化测试证明原子提交、并发冲突、损坏主文件恢复、哈希日志和过期主节点阻断。它不是多可用区实测、备份介质独立性、告警到人或 RTO/RPO 现场证据。只有在目标运行环境中执行定时备份、隔离恢复、节点故障、网络分区、磁盘损坏、秘密轮换和值班演练后，`siteReliabilityAccepted` 才可为 `true`。
