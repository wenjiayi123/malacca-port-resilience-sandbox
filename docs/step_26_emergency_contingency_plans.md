# 第 26 步：应急预案模块

## 完成内容

- 新增 `EmergencyScenarioType`、`EmergencyContingencyPlan` 和 `EmergencyContingencyAssessment` 类型。
- 实现四类应急场景预案：事故封航、极端天气、港口瘫痪、能源管控。
- 事故封航预案综合高风险航道拥堵、航道延误、事件注入压力和机械故障事件判断。
- 极端天气预案综合风速、浪高、能见度和台风预警判断。
- 港口瘫痪预案综合峰值拥堵港口、排队船舶、关键节点压力和事件压力判断。
- 能源管控预案综合总碳排、较基准碳排变化、绿色策略减排收益和当前碳排监测判断。
- 每个预案输出影响区域、触发条件、主处置动作、支撑动作、准备度、预计恢复时间和严重度。
- 底部推演控制台新增“应急预案”面板，展示当前激活预案、平均准备度和四类预案摘要。
- 悬停预案行可查看完整触发条件、主动作、支撑动作、准备度和预计恢复时间。
