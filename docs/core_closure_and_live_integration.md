# 核心闭环与生产接入

当前真实闭环：公开/授权快照 → 事件与可解释派生模型 → 训练段真实算法训练 → 验证段选优 → 检查点 → 最终测试段回放
推理 → 人工采用 → 单船验证请求 → Godot/JSON 结果回写 → 指标与报告更新。

## 港口快照

`port-digital-twin.snapshot.v1` 支持完整场景或按稳定 ID 的遥测增量。生产接口可通过
`VITE_PORT_DATA_ENDPOINT` 配置；浏览器 Token 仅用于本地调试，生产应使用同源服务端网关。

## RL/控制训练

接口见项目 README。训练任务仅在服务器计算，不驱动地图动画。在线推理需要已完成任务的
`jobId`。服务启动时会校验检查点 SHA-256、数据指纹和港口 ID；匹配当前数据集的已完成任务可
恢复到内存，不匹配或被篡改的检查点会被拒绝。

## Godot

网页只接受同源 iframe 消息并校验请求和船舶 ID。文件 JSON 导入仍作为离线调试入口。
预置联动案例和本地参考回写是合成验证，不代表可靠自动桥接已经完成。生产桥接需补充签名、
超时、重试、幂等、版本协商和审计存储。

模块实现状态与现场接入条件见[工程实现说明](./IMPLEMENTATION.md)。
