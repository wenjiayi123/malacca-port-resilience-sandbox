# 第 34 步：联动演示场景

本步骤在 Web 沙盘的“沙盘推演”模块中新增 5 个完整联动演示案例。每个案例都会自动选中船舶、生成 Godot 请求、加载预置微观验证结果，并同步驱动 Web 的风险预警、AI 建议、调度策略和单船报告。

## 演示案例

### 1. 正常通航

- 船舶：`MXS Aurora`
- 航线：西北入口至新加坡主通道
- 风险：无风险事件
- 结果：安全通过、低风险、保持稳定通航航速
- 联动：单船报告显示安全通过，AI 风险判断降为低风险

### 2. 港口拥堵

- 船舶：`Port Klang Express`
- 航线：巴生港至新加坡东向航线
- 风险：新加坡港靠泊拥堵
- 结果：降级通过、中风险、建议降速并错峰靠泊
- 联动：调度策略优先显示错峰到港或分流港口建议

### 3. 事故封航

- 船舶：`Klang Bridge`
- 航线：巴生港至新加坡东向航线
- 风险：东航道事故封航
- 结果：未通过、严重风险、建议限速等待并改道绕行
- 联动：风险预警置顶事故封航验证结果，调度策略提高改道绕行优先级

### 4. 极端天气

- 船舶：`Dumai Feeder 06`
- 航线：杜迈港支线接入航线
- 风险：强对流与低能见度
- 结果：降级通过、高风险、建议低速编队通过
- 联动：AI 建议输出低速、安全间距和天气窗口控制

### 5. 低碳调度优化

- 船舶：`Selat Cargo 12`
- 航线：西北入口至新加坡主通道
- 风险：低碳航速窗口
- 结果：安全通过、低风险、预计单船减排
- 联动：调度策略提高低速航行权重，碳排优化建议显示减排收益

## 操作方式

1. 打开 Web 页面。
2. 切换到底部“沙盘推演”模块。
3. 点击“正常、拥堵、封航、天气、低碳”任一演示按钮。
4. Web 会自动生成该案例的 Godot 请求，并加载该案例的微观验证结果。
5. 观察右侧风险预警、底部单船报告、调度优化模块和 AI 决策建议的同步变化。

## 当前边界
