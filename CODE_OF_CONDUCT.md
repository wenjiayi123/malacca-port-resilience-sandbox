# Code of Conduct / 社区行为准则

We are committed to a respectful, technically rigorous and harassment-free community. Be constructive,
separate evidence from opinion, disclose uncertainty, and never post credentials or restricted port data.

本项目致力于建设尊重、严谨且无骚扰的协作社区。请建设性沟通，区分证据与观点，主动说明不确定性，
并且不得发布凭据、受限港口数据或可识别的敏感运营记录。

Unacceptable behavior includes harassment, discrimination, threats, deliberate deception, unsafe operational
claims, publishing another person's private information, and sustained disruption of technical discussion.

不可接受的行为包括骚扰、歧视、威胁、故意误导、夸大安全或生产能力、公开他人隐私，以及持续扰乱
技术讨论。

Maintainers may edit or remove contributions that violate this policy and may temporarily or permanently limit
participation. Report conduct concerns privately through the maintainer contact method shown on the GitHub
profile; do not disclose sensitive evidence in a public Issue.

维护者可以编辑或删除违规内容，并视情况限制参与。行为问题请通过维护者 GitHub 主页提供的方式私下
联系，不要在公开 Issue 中披露敏感证据。
