# 第 20 步：港口拥堵推演

## 完成内容

- 完成地图层“港口拥堵推演”浮层。
- 基于重点港口的船舶数、排队船舶、泊位数、泊位利用率和平均等待时间派生拥堵推演结果。
- 模拟五个港口作业阶段：到港、排队、靠泊、装卸、离港。
- 计算预计等待时间。
- 计算拥堵分值和拥堵等级，等级包括低拥堵、中拥堵、高拥堵和严重拥堵。
- 拥堵结果会随沙盘控制台的推演时间推进变化。
- 事件注入会对拥堵分值产生压力修正，高风险事件会抬升港口拥堵压力，正向分流事件会降低压力。
- 主卡展示当前最拥堵港口，列表展示排名靠前的拥堵节点。
- 更新 `README.md` 当前阶段和下一步说明。
