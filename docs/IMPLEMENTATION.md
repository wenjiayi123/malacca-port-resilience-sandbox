# 工程实现说明

版本日期：2026-07-21。本文说明港口靠泊协同、TOS/VTS 数据交换、仿真训练平台、
API、安全供应链和可观测性的实现范围；本项目不是 VTS/TOS 认证产品。

## 工程演进

| 模块 | 改进前 | 当前实现 |
|---|---|---|
| RL 进度 | 前端按固定三小时墙钟递增 | 改为轮询服务器真实 episode/评估工作量 |
| RL 指标 | 前端公式生成 loss、KL、GPU 等 | 删除未实际计算指标，只显示环境步、更新次数、状态数、真实奖励 |
| 算法选择 | 展示未训练的 MAPPO/PPO/SAC | 改为真正实现的 4 RL + 1 MPC |
| 训练环境 | 写死随机状态转移 | 改为 CSV/JSON 数据校准的排队控制环境 |
| 数据泄漏 | 测试段曾同时用于算法选优 | 改为 70/15/15 时间切分；验证段选优，最终测试仅由显式评估接口读取 |
| 训练/回放 | 训练时同步展示效果 | 训练阶段暂停策略渲染；完成后由留出 trace 回放 |
| 在线推理 | 写死“已训练 MAPPO”权重 | 必须引用已完成任务 `jobId` 和真实检查点 |
| 仓库体积 | 1.2GB 工作目录、206MB PCK | 仓库排除依赖、软著/构建/导出/运行产物与超限 PCK |
| 视觉许可 | 历史 PNG 缺少可核验再分发依据 | 发布副本使用已登记的小懿原项目身份素材、项目原创 SVG 与本地运行截图 |
| 数据表述 | 离线回退可能被理解为实证 | UI 改为“合成示例（非实证）”并保留证据链 |
| 检查点 | 服务重启丢失可评估/推理任务 | 检查点加入 SHA-256、数据指纹和港口 ID，启动自动验证并恢复 |
| 多港口数据 | 可能混合不同港口时序 | 增加 `port_id` 别名、显式港口选择与重复时间戳拒绝 |
| API 边界 | 任意 JSON、统一 502、无请求上限 | 增加 400/401/404/409/413/415/422/429、1 MiB 上限、请求编号和范围校验 |
| 运行安全 | 开发服务器可被误当生产服务 | 增加独立只读静态服务、Bearer 认证、非本机强制 Token、限流和安全响应头 |
| 运维 | 无 readiness/指标/结构化日志 | 增加 `/healthz`、`/readyz`、JSON 指标和生产请求日志 |
| 港口互操作 | 只有页面内部对象 | 增加 `port-call-event.v1`、JSON Schema 和校验 API，明确仅字段映射而非标准合规声明 |

## 其他模块评估

| 模块 | 当前驱动 | 可信边界 | 后续生产接入 |
|---|---|---|---|
| 总览月度到港/吨位 | MPA data.gov.sg API | 官方月度统计，非实时船位 | 接 MPA/港口统计 API |
| 气象海况 | Open-Meteo 当前模型场 | 模型输出，不用于导航 | 接港区气象站/浮标并保留质量码 |
| AIS 船舶层 | 授权 REST 可选；否则代表船 | 无授权接口时不宣称实时 | 配置 `AIS_REST_ENDPOINT` 与服务端 Token |
| 拥堵与延误 | 可解释排队/事件公式 | 模型估算，非 TOS 实测标签 | 接靠离泊、泊位服务与队列事件 |
| 燃油与碳排 | 船型/航速模型 + IMO 因子 | 估算，受主机与燃料参数影响 | 接 noon report/传感器/燃油台账 |
| 韧性评估 | 拥堵、传播、恢复派生评分 | 决策支持指标，不是行业认证指数 | 用历史故障和恢复标签校准 |
| 规则 AI 建议 | 可解释规则 | UI 已标“规则 AI” | 外部模型需返回来源和置信校准 |
| 小懿操作编排 | 白名单 DOM 动作 | 受控页面操作，非生产自动下发 | 增加 RBAC、审计库、双人确认 |
| 联动案例 | 预置情景 | 合成示例，用于验 UI 闭环 | 由历史事件回放包替换 |
| Godot 单船验证 | Web 导出与消息协议 | 参考回写/导入存在；可靠自动桥接未完成 | 独立进程、签名结果、超时与重试 |

## 现场集成条件

以下内容需要港口授权或独立现场工程：实时 AIS/TOS/VTS 数据、生产
泊位能力、历史事故标签、Godot 原工程的可靠双向执行、港口下发权限与安全认证。仓库已经提供
字段合同、接口、失败关闭和人工确认边界；接入方替换数据与实现协议即可复用训练和 UI。

仓库中的小懿身份视觉使用小懿 AI 原项目同名素材，其余运行视觉使用项目原创 SVG；界面截图由
本仓库本地运行版本生成，来源记录见 `ASSET_PROVENANCE.md`。原工作目录内未登记的历史参考 PNG、
软著材料和导出物不进入仓库。
