# 第 24 步：韧性评估模块

## 完成内容

- 新增 `NetworkResilienceAssessment` 和 `CriticalNodePressure` 派生结果类型。
- 基于港口拥堵推演、船舶延误推演、航道拥堵、风险事件和绿色策略收益计算网络韧性指数。
- 计算拥堵恢复能力，综合关键港口预计恢复小时数、峰值拥堵分值、事件压力和当前推荐策略缓解效果。
- 计算关键节点压力，对新加坡港、巴生港、丹戎帕拉帕斯港等监测港口输出压力分值、加权压力、恢复时间和关联受影响航线数量。
- 计算风险扩散范围，综合受压节点数量、风险航线数量、事件注入压力和恢复能力缺口。
- 将首页“网络韧性指数”核心指标改为动态派生值，随沙盘时间推进、事件注入和绿色策略收益变化。
- 在底部推演控制台新增“韧性评估”紧凑指标条，展示网络韧性指数、恢复能力、关键节点压力和风险扩散范围。
- 悬停韧性评估指标条可查看前三个高压节点的压力分值、拥堵恢复时间和关联航线数量。
