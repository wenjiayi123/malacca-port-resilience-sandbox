# 第 21 步：船舶延误推演

## 完成内容

- 完成船舶延误推演派生计算。
- 综合港口拥堵、天气海况、航速差和航道风险计算每艘船的预计延误。
- 拥堵延误接入第 20 步港口拥堵推演结果，使目的港拥堵会影响到港船舶。
- 天气延误接入风速、浪高、能见度和流速。
- 航速延误根据船舶当前航速与航线平均航速差计算。
- 航道风险延误接入航道状态、航道延误和事件注入压力。
- 地图动态船舶增加延误分钟标签，并按延误等级显示颜色。
- 新增“船舶延误推演”浮层，展示最高延误船舶、四类延误构成和延误排行表。
- 延误结果会随沙盘时间推进和事件注入动态变化。
- 更新 `README.md` 当前阶段和下一步说明。
