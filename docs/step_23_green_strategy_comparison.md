# 第 23 步：绿色调度策略对比

## 完成内容

- 补齐绿色调度策略种子数据，覆盖低速航行、错峰进港、分流港口、优先靠泊和改道绕行五类策略。
- 新增 `GreenStrategyComparison` 派生结果类型。
- 基于第 20 步港口拥堵推演、第 21 步船舶延误推演和第 22 步燃油与碳排核算结果，计算各策略的受影响船舶数、预计延误削减、节油量、碳减排量和拥堵降低比例。
- 根据策略状态、事件压力和当前推演时间动态修正策略收益。
- 新增“绿色调度策略对比”地图浮层，展示推荐策略、综合得分、总体延误削减、总体碳减排和五类策略排行。
- 表格行悬停可查看策略作用对象、动作说明、类型、状态、节油、碳减排和拥堵降低明细。
- 结果会随沙盘时间推进和事件注入动态变化。
