# 控制算法模型卡

版本：`dataset-calibrated-port-control.v2`
用途：港口到港需求、排队、延误、碳强度、气象风险和恢复能力的研究型控制基线比较。

## 方法

仓库实现 Q-Learning、SARSA、Expected SARSA、Dyna-Q 四种表格型强化学习算法，以及模型预测
控制（MPC）基线。四种 RL 执行真实价值函数更新；Dyna-Q 额外执行模型规划回放；MPC 只做需求
模型辨识和滚动优化，不计作 RL。

## 数据与选择协议

- 数据按时间约 70%/15%/15% 划分为训练、验证、最终测试。
- 所有参数更新和 MPC 辨识只读训练段。
- 每种 RL 的超参数只由验证前段选择；五种方法的默认策略只由验证后段选择。
- 最终测试段仅在训练完成后由显式评估接口读取，生成可渲染 trace。
- 检查点保存随机种子、参数、港口 ID、数据指纹、三段范围、质量摘要、五种策略和 SHA-256。
- `pnpm benchmark:rl` 在多个随机种子上输出全部五种方法的留出结果；报告同时绑定训练引擎、数据
  加载器、目标预设、基准脚本、包清单和锁文件的 SHA-256，可用 `pnpm benchmark:rl:verify` 复核。

## 预期用途

- 教学、算法复现、公开数据研究、港口适配器开发和离线方案比较。
- 在接入方自己的历史 TOS/VTS/AIS/气象数据上开展离线验证。

## 禁止用途

- 不得直接控制 VTS、TOS、船舶、泊位、引航或拖轮设备。
- 不得把 MPA 月度样例的结果解释为泊位级实时调度效果。
- 不得把模型的碳排、拥堵、延误或韧性输出描述为实测或认证指标。
- 未经过安全约束、港口规则校核和人工批准，不得用于生产下发。

## 已知限制

- 默认公开数据为月度聚合，到港服务能力使用训练段统计代理；ERA5 风速覆盖完整，但浪高、能见度和
  安全字段缺失，因此完整气象向量覆盖率仍为 0。
- 表格状态会离散化连续港口过程；未实现深度 RL 或多智能体协同。`pnpm benchmark:rl` 提供多随机
  种子均值/标准差，但不能替代现场置信区间或业务验收。
- 压力/天气泛化测试是对最终测试记录施加文档化扰动，不是新的现场观测。
- 单实例检查点适合参考部署；多实例应使用任务数据库、对象存储、队列和模型审批系统。

## 复现与验收

运行 `pnpm release:check`。测试会验证三段时间隔离、真实参数更新、五策略存在、最终测试时间戳、
多港口选择、重复时间戳拒绝、检查点摘要以及新进程恢复。任何指标对比都应同时报告数据指纹、
港口 ID、随机种子、算法参数和运行版本。
