# 第 22 步：燃油与碳排核算

## 完成内容

- 完成燃油与碳排核算派生计算。
- 按船型配置日燃油消耗、等待辅机油耗和参考航速。
- 按航线配置估算航程。
- 根据船舶当前航速使用航速立方修正估算航行燃油消耗。
- 根据第 20 步港口拥堵推演和第 21 步船舶延误推演估算等待时间和等待燃油消耗。
- 使用燃油碳排系数换算单船碳排放。
- 与基准航速和基准等待时间下的碳排放对比，输出碳排变化比例。
- 新增“燃油与碳排核算”地图浮层，展示总燃油、总碳排、较基准变化和单船排行。
- 表格行悬停可查看航程、航速、等待时间、燃油和碳排明细。
- 结果会随沙盘时间推进、港口拥堵、船舶延误和事件注入动态变化。
- 更新 `README.md` 当前阶段和下一步说明。
