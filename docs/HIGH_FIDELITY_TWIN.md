# 耦合港口数字孪生忠实度框架

`coupled-port-twin-profile.v1` 将航道、潮位、船舶吃水与下沉量、泊位长度/水深/岸桥约束、装卸离散事件、堆场 TEU 质量守恒、集疏运出场、设备能耗和电网碳因子放入同一确定性时钟。每一步都输出独立快照摘要和以下不变量：

- 每个泊位最多一色船，船长和泊位安全余量必须满足。
- 航道可用水深减吃水和速度相关下沉量必须高于最小富余水深，否则当步航行失败关闭。
- `yard(t)=yard(t-1)+discharged-loaded-gateOut`，堆场库存不得为负或超容量。
- 岸桥作业量不得超过岸桥数、泊位限制、单机效率和剩余作业量；能耗由活跃岸桥与辅助负荷积分。
- 同一标定剖面、初态、步长和控制输入生成相同快照摘要。

标定剖面对每个输入保留来源 ID、SHA-256、测量/工程属性、独立复核和现场验收编号。只有水深测量、潮位站、实船试验和设备电表四类证据都实测、独立复核并绑定验收编号时，`operatorCalibrated` 才可为 `true`。

当前框架是一维航道运动学、确定性岸桥作业率和聚合堆场库存，不冒充全流体力学、六自由度操纵模型或箱级码头操作系统。现场还需水文测量、船模系数辨识、设备台账/故障分布、箱级作业回放、软件在环/硬件在环校准和运营方签字。在此之前 `hilConnected=false`、`fieldAcceptanceCompleted=false`、`dispatchAllowed=false`。
