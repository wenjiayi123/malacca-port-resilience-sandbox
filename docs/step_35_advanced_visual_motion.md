# 第 35 步：高级视觉动效打磨

本步骤对 Web 大屏进行高级视觉动效增强，重点保持现有业务逻辑、模块结构和布局尺寸不变，只在已有地图、面板、雷达、热力图、指标和告警节点上增加动效层。

## 已完成效果

1. 流光航线

- 主地图航线新增独立流光路径层，不影响原 SVG 航线点击和船舶 `animateMotion` 路径。
- 航线基础虚线增加流动效果，风险航线使用黄色或红色流光增强风险识别。
- 左侧小地图航线同步加入虚线流动。

2. 船舶尾迹

- 每艘动态船舶增加宽尾迹和上下两条水迹线。
- 尾迹按船舶风险颜色轻微脉冲，选中船舶时仍保留原高亮状态。

3. 扫描雷达

- 气象与海况雷达增加旋转扫描扇面。
- 雷达增加双层扩散 ping，用于表达实时扫描。
- 中央地图区域增加低透明度雷达扫面，不遮挡港口、航线和浮层文字。

4. 告警闪烁

- 顶部告警胶囊增加红色和黄色闪烁节奏。
- 风险预警卡片增加呼吸式内发光。
- 航道状态点增加轻微脉冲，危险和预警状态更醒目。

5. 面板发光

- KPI 条、HUD 面板、港口拥堵、船舶延误、燃油碳排和绿色调度浮层统一增加亮度呼吸。
- KPI 卡片和热力图卡片增加横向光带扫过。
- 面板动效使用滤镜和伪元素，不改变布局尺寸。

6. 数字滚动

- 顶部 KPI、左侧统计、船舶分类总数、碳排关键值和底部模块摘要接入数字滚动组件。
- 数字按字符逐位进入，保留原单位和文字布局。

7. 热力渐变

- 航道拥堵热力图增加热力光斑呼吸、航线热流和色带渐变流动。
- 热点大小、颜色和数值仍由原拥堵强度数据驱动。

## 验证结果

- `pnpm build` 通过。
- 浏览器打开 `http://127.0.0.1:5180/` 验证主屏和“沙盘推演”模块。
- 页面运行时控制台无 warning 和 error。
- DOM 验证结果：5 条流光航线、7 个宽尾迹、14 条船舶水迹、1 个雷达扫描扇面、2 个雷达扩散 ping、5 个沙盘演示按钮均正常渲染。

## 当前边界

- 本步骤只打磨 Web 可视化动效，不修改 Godot 桥接逻辑。
- 动效遵守 `prefers-reduced-motion: reduce`，系统开启减少动态效果时会自动收敛动画。
