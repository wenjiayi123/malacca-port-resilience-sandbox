# 保留科技视觉并扩充港航态势交互

日期：2026-10-24

用户明确要求保留原先类似卫星地图的未来科技视觉。本次将科技态势恢复为默认主视图，上一轮的连接关系图保留为辅助视图；共享同一场景中的港口、航段、样船、拥堵及延误数据。

## 视觉与操作

- 沿用原有 `public/assets/backgrounds/malacca_background_clean.png` 夜景资源，恢复海岸灯光、海峡空间感，并增加动态航段、扫描光效、港口信标和方向编号。
- 港口标签通过引线连接锚点，明确国家、排队、状态及观察节点。位置是配合视觉底图的空间关系示意，没有把插画包装成导航坐标。
- 支持航段、拥堵热区、事件影响、动态光效与船流独立切换；动效遵从系统减少动画设置。
- 点选航段、港口和样船时显示地图内摘要与完整业务详情。完整详情包含起讫港、航道、流量、延误、航速、拥堵、关联船舶或船舶延误分量。
- 支持对象聚焦、缩放、放大后拖拽、缩略图恢复全域、清除选择和全部视图重置。标签与编号在缩放时保持可读尺寸。
- 新增专注大屏，保留详情侧栏与图层筛选。Escape 可退出，Tab 保持在大屏操作范围内；进入港口韧性或单船验证时自动退出专注视图。
- 搜索、航段分类筛选、关系图、原有仿真分析图层与授权卫星/AIS 入口保留。
- 演示开场改为调用原生科技态势按钮并重置视图，避免上次的聚焦、筛选或隐藏图层影响开场。

## 实测修复

- 修复专注模式被旧侧栏与导航遮挡的问题。
- 将航段编号改为独立原生按钮，修复样船遮挡编号导致点选错误的问题；短航段 R05 也可直接点选。
- 地图使用裁切而非可滚动隐藏区域，修复点选后内部滚动造成底图、HUD 偏移的问题。
- 将新加坡港标签移离南部汇流区，避免遮挡样船；完整样船详情会滚动到船舶内容，而不是只显示航段标题。
- 两种视图都从配置的端点生成连接；平行与反向航段分离，缺失端点不绘制推测连接。
