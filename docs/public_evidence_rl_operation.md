# 公开实证与控制算法操作

## 公开数据

系统默认进入“公开实证”模式：

- MPA/data.gov.sg 月度到港船舶数与总吨位；
- Open-Meteo 当前天气、风浪、海流和海温模型场；
- IMO 燃料碳因子；
- AIS 公开研究只作为统计背景，未配置授权接口时不生成伪实时船位。

打开“系统设置”可查看每项证据链接、数据期和授权接口状态。接口失败时状态切换为“合成数据
回退”，此时数据不能作为实证引用。

## 训练

1. 进入“沙盘推演”，打开“港口控制算法训练中心”。
2. 在算法选择中选择主策略；所有任务仍统一训练/辨识 4 RL + 1 MPC，所选算法用于后续回放。
3. 设置训练优化目标、价值更新步长、折扣因子、episode、种子和奖励权重。
4. 点击“测试接入”，确认 `/api/rl/health` 返回 `rl-training-job.v1`。
5. 点击“启动训练”。地图策略动画暂停；进度来自服务器实际工作量。
6. 查看港口 ID、数据指纹、训练/验证/最终测试记录数、当前算法、环境步、参数更新与 Reward EMA。
7. 训练完成后查看五种方法的真实曲线和验证集指标；最终测试指标只在点击策略测试后出现。
8. 下载 checkpoint，或选择闭环/拥堵/天气测试并点击“启动测试”。

测试进度按服务返回的 trace 逐步推进。压力测试只变换留出测试记录，不回流训练。

## 在线推理

在线推理必须先有当前服务内已完成任务。点击“RL 策略推理”后，服务读取所选检查点，输出动作
价值分布、检查点元数据、最终测试集来源、单步模型投影和人工确认边界。没有 `jobId` 时返回 409，
不会降级为写死策略。
