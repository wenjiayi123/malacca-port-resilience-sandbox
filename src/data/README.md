# Scenario Data

`malaccaScenario.ts` contains the current front-end seed scenario for the sandbox.

The seed is the explicit synthetic fallback. The runtime adapter can merge public-evidence or authorized
snapshots by stable IDs without changing the HUD layout contract.

Current seed data includes port nodes, channel status, route-level shipping flows, animated vessel markers, weather, carbon snapshots, alerts, congestion heatmap inputs, and green scheduling strategies.
